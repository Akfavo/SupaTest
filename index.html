💡 Aide-Mémoire & Modèles SQL RLS Supabase

            

              Copiez ces modèles prêts à l'emploi directement dans le SQL Editor de votre projet Supabase.
            

          

          
        

        

          
          

            

              
🛡️ 1. L'utilisateur accède uniquement à ses propres données

              
            

            

              Garantit qu'un utilisateur connecté ne peut ni voir, ni modifier, ni supprimer les lignes appartenant à d'autres utilisateurs.
            

            
CREATE POLICY "Utilisateurs accèdent à leurs propres lignes"
ON posts FOR ALL TO authenticated
USING (auth.uid() = user_id)
WITH CHECK (auth.uid() = user_id);

          


          
          

            

              
👑 2. Accès réservé au rôle Administrateur (RBAC)

              
            

            

              Permet uniquement aux comptes ayant le rôle admin dans leur app_metadata d'effectuer l'opération.
            

            
CREATE POLICY "Admins ont tous les droits"
ON posts FOR ALL TO authenticated
USING ((auth.jwt() -> 'app_metadata' ->> 'role') = 'admin');

          


          
          

            

              
👁️ 3. Lecture publique (Anon), écriture pour utilisateurs connectés

              
            

            

              Idéal pour des blogs, cours ou catalogues : tout le monde peut lire (SELECT), mais seuls les connectés peuvent créer (INSERT).
            

            
CREATE POLICY "Lecture publique" ON posts FOR SELECT TO public USING (true);
CREATE POLICY "Insertion membres" ON posts FOR INSERT TO authenticated WITH CHECK (auth.uid() = user_id);

          


          
          

            

              
🏢 4. Multi-Tenant (Isolation par Organisation ou Équipe)

              
            

            

              Permet aux membres d'une même équipe ou entreprise de partager des documents sans fuite de données vers d'autres clients.
            

            
CREATE POLICY "Membres de la même organisation"
ON documents FOR ALL TO authenticated
USING (organisation_id IN (SELECT org_id FROM user_organisations WHERE user_id = auth.uid()));

          


          
          

            

              
⚡ 5. Template complet : Activer RLS & politique CRUD par défaut

              
            

            

              La commande standard à exécuter lors de la création d'une nouvelle table pour activer la sécurité en base.
            

            
ALTER TABLE ma_table ENABLE ROW LEVEL SECURITY;
CREATE POLICY "CRUD pour le propriétaire" ON ma_table FOR ALL TO authenticated USING (auth.uid() = user_id);
